# Frontend

Interface React da Comunidade Digital Escolar (logotipo GERABRIEL).

```bash
cp .env.example .env
npm install
npm run dev
```

Abre **http://localhost:5173** com recarregamento automático (Go Live). Ver [`PREVIEW.md`](PREVIEW.md).

Acesso só por **login** — contas criadas pela escola (admin). Email `@epgerabriel.edu.pt`.
